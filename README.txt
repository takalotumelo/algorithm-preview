ALGORITHM WEBSITE: GITHUB PAGES PREVIEW
=======================================

A preview build for GitHub Pages. It works at any address, including a project
site like https://<your-username>.github.io/algorithm-preview/
It is marked "noindex" so Google won't list it next to Algorithm's real site.

PUBLISH IT
1. On github.com: New repository > name it algorithm-preview > Public > Create.
2. Upload the CONTENTS of this folder (index.html, assets/, blog/, .nojekyll ...),
   not the zip itself. Easiest with GitHub Desktop or git; the web uploader takes
   at most 100 files per upload, so you would need several rounds.
3. Repository > Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After a minute or two the site is live at https://<your-username>.github.io/algorithm-preview/

ENQUIRY FORM
The form posts to Formspree. Replace https://formspree.io/f/YOUR_FORM_ID in
need-assistance/index.html with your own Formspree endpoint (free at formspree.io).
Until then the form shows a "didn't send" message with the phone number and email.
